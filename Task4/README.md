# RAG Telegram-бот

Telegram-бот с RAG-пайплайном для ответов на вопросы по базе знаний фэнтези-мира.

## Архитектура

```
Пользователь (Telegram)
        │
        ▼
   Telegram Bot API
        │
        ▼
  ┌─────────────────┐
  │  Query Embedding │  ← intfloat/multilingual-e5-large
  │  (prefix: query:)│
  └────────┬────────┘
           ▼
  ┌─────────────────┐
  │   FAISS Search   │  ← IndexFlatIP (cosine similarity)
  │   top-5 chunks   │
  └────────┬────────┘
           ▼
  ┌─────────────────┐
  │  Prompt Builder  │  ← Few-shot + Chain-of-Thought
  │  (system + user) │
  └────────┬────────┘
           ▼
  ┌─────────────────┐
  │   Llama 3 (LLM) │  ← Ollama API
  │   via Ollama     │
  └────────┬────────┘
           ▼
     Ответ + источники
```

## Техники промптинга

### Few-shot
В системный промпт включены 2 примера вопросов и ответов в формате Q/A,
**извлечённых из реальных данных базы знаний** (не придуманных):

| # | Источник в базе | Вопрос | Ключевые факты |
|---|----------------|--------|----------------|
| 1 | `Verdania.txt` | Где расположена Вердания и кто ей управляет? | Скрытая деревня Царства Углей, управляется Архонтом, всего 7 Архонтов |
| 2 | `Toren_Solwind.txt` | Who is Toren Solwind? | Страж клана Солвинд, носитель Багрового Зверя с рождения, Седьмой Архонт |

Каждый пример демонстрирует:
- Формат ответа Q/A
- Пошаговое рассуждение (Chain-of-Thought) перед финальным ответом
- Использование только фактов из контекста

### Chain-of-Thought
Модель инструктирована рассуждать пошагово перед формированием финального ответа:
1. Анализ контекстных фрагментов
2. Выделение релевантных фактов
3. Синтез ответа

Пользовательский промпт также использует Q/A формат:
```
Q: [запрос пользователя]
A: Let me reason step-by-step based on the context fragments above.
```

## Переменные окружения

| Переменная | Описание | По умолчанию |
|-----------|----------|-------------|
| `TELEGRAM_BOT_TOKEN` | Токен Telegram-бота (обязательно) | — |
| `OLLAMA_HOST` | Адрес Ollama API | `http://localhost:11434` |
| `OLLAMA_MODEL` | Модель для генерации | `llama3` |
| `TOP_K` | Количество чанков контекста | `5` |

## Запуск

```bash
# 1. Убедитесь, что Ollama запущена с моделью Llama 3
ollama pull llama3
ollama serve

# 2. Установите зависимости
make install

# 3. Запустите бота
export TELEGRAM_BOT_TOKEN="your-token-here"
make bot
```

## Команды бота

| `/help` | Описание работы бота |
