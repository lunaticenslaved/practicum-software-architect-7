# RAG Telegram-бот и консольный клиент

Telegram-бот и консольный клиент с RAG-пайплайном для ответов на вопросы по базе знаний фэнтези-мира.

## Архитектура

```
                    ┌──────────────────┐
                    │   rag_engine.py  │  ← общая RAG-логика
                    │                  │
                    │  RAGEngine       │  FAISS + Embeddings + Ollama
                    │  SYSTEM_PROMPT   │  Few-shot + CoT
                    │  build_rag_prompt│
                    └────────┬─────────┘
                             │
              ┌──────────────┼──────────────┐
              ▼                             ▼
     ┌────────────────┐            ┌────────────────┐
     │    bot.py       │            │    cli.py       │
     │  Telegram-бот   │            │  Консольный     │
     │  (python-       │            │  клиент (REPL   │
     │   telegram-bot) │            │  или одиночный  │
     └────────────────┘            │  запрос)        │
                                   └────────────────┘
```

### RAG-пайплайн (общий для обоих клиентов)

```
Запрос пользователя
        │
        ▼
  ┌─────────────────┐
  │  Query Embedding │  ← intfloat/multilingual-e5-large
  │  (prefix: query:)│
  └────────┬────────┘
           ▼
  ┌─────────────────┐
  │   FAISS Search   │  ← IndexFlatIP (cosine similarity)
  │   top-5 chunks   │
  └────────┬────────┘
           ▼
  ┌─────────────────┐
  │  Prompt Builder  │  ← Few-shot + Chain-of-Thought
  │  (system + user) │
  └────────┬────────┘
           ▼
  ┌─────────────────┐
  │   Llama 3 (LLM) │  ← Ollama API
  │   via Ollama     │
  └────────┬────────┘
           ▼
     Ответ + источники
```

## Структура файлов

| Файл | Описание |
|------|----------|
| `rag_engine.py` | RAG-движок: FAISS-поиск, эмбеддинги, промпт, Ollama LLM |
| `bot.py` | Telegram-бот, импортирует `rag_engine` |
| `cli.py` | Консольный клиент, импортирует `rag_engine` |

## Техники промптинга

### Few-shot
В системный промпт включены 2 примера вопросов и ответов в формате Q/A,
**извлечённых из реальных данных базы знаний** (не придуманных):

| # | Источник в базе | Вопрос | Ключевые факты |
|---|----------------|--------|----------------|
| 1 | `Verdania.txt` | Где расположена Вердания и кто ей управляет? | Скрытая деревня Царства Углей, управляется Архонтом, всего 7 Архонтов |
| 2 | `Toren_Solwind.txt` | Who is Toren Solwind? | Страж клана Солвинд, носитель Багрового Зверя с рождения, Седьмой Архонт |

Каждый пример демонстрирует:
- Формат ответа Q/A
- Пошаговое рассуждение (Chain-of-Thought) перед финальным ответом
- Использование только фактов из контекста

### Chain-of-Thought
Модель инструктирована рассуждать пошагово перед формированием финального ответа:
1. Анализ контекстных фрагментов
2. Выделение релевантных фактов
3. Синтез ответа

Пользовательский промпт также использует Q/A формат:
```
Q: [запрос пользователя]
A: Let me reason step-by-step based on the context fragments above.
```

## Переменные окружения

| Переменная | Описание | По умолчанию |
|-----------|----------|-------------|
| `TELEGRAM_BOT_TOKEN` | Токен Telegram-бота (только для bot.py) | — |
| `OLLAMA_HOST` | Адрес Ollama API | `http://localhost:11434` |
| `OLLAMA_MODEL` | Модель для генерации | `llama3` |
| `TOP_K` | Количество чанков контекста | `5` |

## Запуск

### Предварительные шаги

```bash
# 1. Убедитесь, что Ollama запущена с моделью Llama 3
ollama pull llama3
ollama serve

# 2. Установите зависимости
make install
```

### Консольный клиент (рекомендуется для проверки)

```bash
# Интерактивный режим (REPL)
make cli

# Одиночный запрос
make cli QUERY="Who is Toren Solwind?"
make cli QUERY="Где расположена Вердания?"
make cli QUERY="Tell me about the Great Convergence War"
```

В интерактивном режиме:
- Введите вопрос и нажмите Enter
- Для выхода: `quit`, `exit`, `q` или `Ctrl+C`

### Telegram-бот

```bash
export TELEGRAM_BOT_TOKEN="your-token-here"
make bot
```
