# Задание 6. Автоматическое обновление базы знаний

Скрипт `update_index.py` инкрементально обновляет БЗ и FAISS-индекс:
сканирует `Task6/docs/`, сравнивает SHA-256 хеши с манифестом, синхронизирует
изменения в `Task2/knowledge_base/`, чанкирует и эмбеддирует только изменённые файлы.

## Алгоритм

1. Сканирование `docs/` → SHA-256 хеши всех `*.txt`
2. Сравнение с `manifest.json` → определение добавленных / изменённых / удалённых
3. Синхронизация `docs/` → `Task2/knowledge_base/`
4. Чанкинг только новых/изменённых файлов
5. Генерация эмбеддингов только для новых чанков
6. Пересборка FAISS-индекса (`IndexFlatIP`)
7. Логирование: консоль + файл + JSON-резюме

Если манифест отсутствует (первый запуск), все файлы из `docs/` считаются новыми.

## Запуск

```bash
# Добавить новый документ
cp new_article.txt Task6/docs/

# Запустить обновление
make update-index
```

## Структура файлов

| Файл | Описание |
|------|----------|
| `update_index.py` | Скрипт инкрементального обновления |
| `architecture.puml` | PlantUML-диаграмма потока данных |
| `cron.txt` | Cron-задача (`0 6 * * *` — ежедневно в 06:00) |
| `docs/` | Папка-источник (симуляция внешнего источника) |
| `manifest.json` | SHA-256 хеши docs/ с последнего запуска (авто) |
| `logs/` | Лог-файлы и JSON-резюме |

## Cron

```bash
crontab Task6/cron.txt   # установка
crontab -r               # удаление
```

## Обработка ошибок

- `try/except` → traceback в лог + JSON-резюме со статусом `"ERROR"`
- Код выхода: `0` — успех, `1` — ошибка
- stdout/stderr → `Task6/logs/update.log` (через crontab)

## Резюме обновления

После каждого запуска создаётся `Task6/logs/last_update_summary.json`:

```json
{
  "status": "OK",
  "duration_sec": 15.3,
  "files": { "added": 2, "modified": 1, "deleted": 0 },
  "chunks": { "new": 12, "removed": 5, "total_index_size": 3674 },
  "error": null
}
```

## Совместимость

- Параметры чанкинга и модель эмбеддингов идентичны `Task3/`
- Выходные файлы: `chunks.jsonl`, `embeddings.jsonl`, `index.faiss`, `metadata.json`
- `Task4/rag_engine.py` подхватывает обновлённый индекс при следующем запуске
