# Эмбеддинги и векторный индекс

## Эмбеддинг-модель

**`intfloat/multilingual-e5-large`** — мультиязычная модель на базе XLM-RoBERTa Large (1024-dim, макс. 512 токенов). Поддерживает 100+ языков. Требует префикс `query:` для поисковых запросов и `passage:` для индексируемых документов.

## База знаний

35 текстовых файла из `Task2/knowledge_base/` — вики-страницы фэнтези-мира с заменёнными терминами (см. `Task2/terms_map.json`).

## Параметры чанкинга

| Параметр | Значение |
|----------|----------|
| Файлов в БЗ | 35 |
| Размер чанка | 800 символов |
| Перекрытие | 150 символов |
| Мин. размер чанка | 30 символов |
| Всего чанков | 3 655 |

## Генерация эмбеддингов

| Параметр | Значение |
|----------|----------|
| Размер батча | 8 |
| Время генерации | ~32 минуты (CPU) |
| Размер файла | 82 МБ (`output/embeddings.jsonl`) |

## FAISS-индекс

| Параметр | Значение |
|----------|----------|
| Тип индекса | `IndexFlatIP` (cosine similarity для L2-нормализованных векторов) |
| Документов | 3 655 |
| Размер индекса | 15 МБ (`faiss_index/index.faiss`) |
| Метаданные | 2.7 МБ (`faiss_index/metadata.json`) |

## Запуск

```bash
# 1. Чанкинг + эмбеддинги
make chunks

# 2. FAISS-индекс
make index

# 3. Поиск
make search QUERY="Who is Toren Solwind?"
```
